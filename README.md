# Petalnotes

Notes, finds, and everyday life.

网站源码、内容及部署统一在本仓库维护：[访问网站](https://fanhuajin.github.io/)。

修改本仓库并推送到 `master` 后，由 GitHub Pages 自动发布。跨仓库自动同步已移除，无需维护两份网站代码。

资源内容在 `assets/resources.json`，页面交互在 `app.js`，样式在 `style.css`。修改 JS、CSS 后同步更新 HTML 中的资源版本号；修改页面入口时同步根目录及 `home`、`tags`、`lists`、`list` 下的入口 HTML。

[fieldnotes](https://github.com/fanhuajin/fieldnotes) 仓库仅保留历史源码与下载 Releases，现有软件下载链接继续使用。
